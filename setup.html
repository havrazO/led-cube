Set up the Arduino IDE

Do this once on your MacBook, in your own account. It takes about 15 minutes and needs the internet.

The course is tested with these versions: Arduino IDE 2.3.10, board package arduino-pico 6.2.0, Adafruit NeoPixel 1.15.5 and ArduinoJson 7.4.3. When the IDE offers an update for them during the course, decline it: newer versions are not tested with the cube.

  1. Open the Arduino IDE and its settings (menu Arduino IDE > Settings).
  2. Add this line to “Additional boards manager URLs” and click OK:
    https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json
  3. Open the Boards Manager (left side bar), search for “pico” and install Raspberry Pi Pico/RP2040/RP2350 by Earle F. Philhower, version 6.2.0.
  4. Open the Library Manager, install Adafruit NeoPixel version 1.15.5 and ArduinoJson version 7.4.3.
  5. Choose the board: Tools > Board > Raspberry Pi Pico/RP2040/RP2350 > Raspberry Pi Pico 2W.
  6. Test: open File > Examples > 01.Basics > Blink and click the tick button (Verify). You are done when it ends with “Done compiling”.

If the test shows an error, take a screenshot and bring it to the first session.
