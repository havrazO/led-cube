# LED Cube: From Bits to AI

Course material for building and programming a 4 × 4 × 4 LED cube.

Read it as web pages: **https://havrazo.github.io/led-cube/**

Start with the setup page, then open the session of the day. New sessions appear shortly before they start. The firmware skeleton for your cube (folder `firmware/`) comes with Session 4: copy it once into your Arduino folder and work only there.
